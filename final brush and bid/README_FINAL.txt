BRUSH and BID — COMPLETE UPDATED PROJECT
=========================================
This package keeps the public, bidder, artist and admin pages together.

Included:
- Shared login/profile icon on every page.
- Profile icon uses the first letter of the registered user's name.
- Role-specific navigation for Bidder, Artist and Admin.
- Logout and profile navigation.
- Professional Playfair Display + DM Sans typography.
- Gallery API loading made more tolerant of backend response formats.
- Gallery supports normal image URLs and raw base64 artwork images.
- Existing HTML/CSS/JS/SQL files retained.

IMPORTANT:
- Keep your existing server.js/backend running from the same project setup.
- The frontend calls /api/... endpoints from the current backend.
- If your backend is in this folder, start it with its normal command.
